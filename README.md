# 🎵 Spotify Mod (Zero Ads + Offline Downloader + Auto-Proxy)

Полноценная модификация для десктопного Spotify (Windows) с полным отключением рекламы, нативной кнопкой скачивания треков и плейлистов в высоком качестве, офлайн-воспроизведением и автоматическим распознаванием локальных прокси (v2ray, Clash, sing-box и др.).

---

## ⚡ Быстрая установка (1 клик)

### Вариант 1: Через PowerShell (Самый быстрый и рекомендуемый)
Нажми `Win + X` ➔ выбери **PowerShell** (или `Win + R` ➔ введи `powershell`) и вставь команду:

```powershell
irm https://raw.githubusercontent.com/YourUsername/spotify-mod/main/install.ps1 | iex
```

### Вариант 2: Для тех, кто не хочет открывать консоль
1. Скачай архив со страницы [Releases](https://github.com/YourUsername/spotify-mod/releases).
2. Распакуй архив в любую удобную папку.
3. Запусти файл `Install.bat` двойным кликом мыши.

---

## 🌟 Что умеет мод

1. **Полное отсутствие рекламы (Zero Ads)**:
   - Патчинг ядра `productStateApi` (аккаунт работает как Premium: `ads: '0'`, `unrestricted: '1'`).
   - Никаких 30-секундных аудиовставок между треками.
   - Чистый интерфейс без рекламных баннеров и всплывающих окон.

2. **Офлайн-скачивание треков и плейлистов**:
   - Нативная кнопка со стрелкой скачивания в шапке любого плейлиста.
   - Кнопка быстрой загрузки играющего трека в панели управления звуком.
   - Мульти-источник скачивания (SoundCloud + резервный поиск) — треки качаются на высокой скорости без блокировок DPI и задержек.
   - Все файлы автоматически сохраняются в папку `Музыка\Spotify Downloads\` с тегами и обложками.
   - Встроенный плеер для офлайн-воспроизведения прямо в интерфейсе Spotify.

3. **Автоопределение локальных прокси**:
   - Автоматически находит запущенные прокси: **v2rayN / Xray** (`10808`), **Clash / Verge / Mihomo** (`7890`), **sing-box / NekoRay** (`2080`), **WARP** (`40000`), **Shadowsocks** (`1080`).
   - Если прокси выключен — **не падает с ошибкой**, а плавно работает напрямую.

4. **Работает у любого пользователя из коробки**:
   - Не требует установленного Node.js, Python, Git или компиляторов.
   - Автоматически находит Spotify (AppData, LocalAppData, Program Files). Если Spotify не установлен — скачивает официальный Win32 клиент.
   - Исправляет права доступа Crashpad, исключая ошибки `0x5 Access Denied` и серые экраны.
   - Фоновая служба `SpotifyCompanionDaemon` работает бесшумно и автоматически запускается при входе в Windows.

---

## 🗑 Удаление мода
Чтобы вернуть Spotify в исходное заводское состояние:
Запусти в PowerShell:
```powershell
& ".\uninstall.ps1"
```
Скрипт восстановит исходный `xpui.spa.bak`, уберет службу из автозагрузки и очистит кэш.
