## 🏛 Архитектура и принцип работы

Мод работает как гибрид из двух независимых компонентов: **клиентского хука** внутри оболочки Spotify (CEF/Chromium) и **фонового микросервиса** (Companion Daemon).

```
┌───────────────────────────────────────────────────────────┐
│                    Spotify Desktop (CEF)                  │
│                                                           │
│   ┌─────────────────────┐       ┌─────────────────────┐   │
│   │   Core Patches      │       │     Mod Bundle      │   │
│   │   (xpui.js)         │       │     (bundle.js)     │   │
│   │                     │       │                     │   │
│   │ • productStateApi   │       │ • Encore UI Buttons │   │
│   │ • Audio ads bypass  │       │ • Settings Modal    │   │
│   │ • Banner stripping  │       │ • Audio Player Hook │   │
│   └─────────────────────┘       └──────────┬──────────┘   │
└────────────────────────────────────────────┼──────────────┘
                                             │ HTTP IPC (127.0.0.1:43821)
                                             ▼
┌───────────────────────────────────────────────────────────┐
│              Spotify Companion Daemon (.NET + Node)       │
│                                                           │
│  ┌───────────────────────┐     ┌───────────────────────┐  │
│  │  Smart Proxy Prober   │     │  Multi-Tier Resolver  │  │
│  │                       │     │                       │  │
│  │ • 10808 (v2ray/Xray)  │     │ 1. SoundCloud (M4A)   │  │
│  │ • 7890 (Clash/Mihomo) │     │ 2. YouTube (Fallback) │  │
│  │ • 2080 (sing-box)     │     │ 3. Direct Streaming   │  │
│  │ • Zero-Hang Fallback  │     │                       │  │
│  └───────────────────────┘     └───────────┬───────────┘  │
└────────────────────────────────────────────┼──────────────┘
                                             │ Auto-tag & Save
                                             ▼
                                ┌─────────────────────────┐
                                │ %USERPROFILE%\Music\    │
                                │ └── Spotify Downloads\  │
                                └─────────────────────────┘
```

1. **In-Memory Client Injection:** Модифицированный `bundle.js` внедряется напрямую в архив интерфейса `xpui.spa`. Он бесшовно интегрируется в дизайн-систему Spotify Encore: кнопки загрузки встраиваются в тулбар плейлиста и панель управления воспроизведением.
2. **Изолированный фоновый демон:** Управление загрузками вынесено в локальный сервис на `127.0.0.1:43821`. Он не нагружает процесс рендерера Spotify, не блокирует UI и автоматически перезапускается через супервизор на C#.

## 🚀 Быстрая установка

Для установки **не требуется** заранее ставить Node.js, Python, Git или компиляторы — все необходимые компоненты автономны.

### Способ 1: PowerShell One-Liner (Рекомендуемый)

Откройте **PowerShell** (`Win + X` ➔ *Терминал* или *Windows PowerShell*) и выполните:

```powershell
irm https://raw.githubusercontent.com/YourUsername/spotify-mod/main/install.ps1 | iex
```

*Скрипт автоматически найдет установленный Spotify (или установит официальный Win32, если клиента нет), выставит правильные ACL-права, настроит автозапуск службы и запустит модифицированный клиент за 15 секунд.*

### Способ 2: Автономный архив (Install.bat)

1. Перейдите в раздел [**Releases**](https://github.com/YourUsername/spotify-mod/releases) и скачайте архив `spotify-mod-latest.zip`.
2. Распакуйте содержимое в любую директорию.
3. Запустите файл `Install.bat` двойным кликом.

## ⚙️ Техническое описание механик

### 1. Блокировка рекламы на уровне ядра (productStateApi)

Большинство скриптовых блокировщиков пытаются глушить аудиорекламу «вслепую» через манипуляции с HTML5-тегом `<audio>` или перехватом `window.fetch`. В современных версиях Spotify аудиопоток декодируется внутренним нативным аудиодвижком CEF в обход JS DOM, что в старых модах приводило к проигрыванию 30-секундных тихих пауз.

В нашем моде используется патчинг `productStateApi`:
- Значения `ads: '0'`, `catalogue: 'premium'`, `product: 'premium'`, `type: 'premium'` и `unrestricted: '1'` инжектируются в состояние сессии до инициализации сетевого стека Cosmos.
- Бэкэнд Spotify отдает метаданные треков как для аккаунта с подпиской Premium: интервалы спонсорских вставок физически исключаются из очереди воспроизведения.
- Дополнительный MutationObserver безопасно удаляет рекламные заглушки, не затрагивая всплывающие контекстные меню и модальные окна.

### 2. Подсистема офлайн-скачивания (Companion Daemon)

Скачивание защищенного потока Spotify напрямую с CDN невозможно без ключей DRM Widevine L3. Мод решает эту задачу с помощью локального микросервиса:
- При клике на кнопку «Скачать плейлист» мод считывает метаданные треков (исполнитель, название, альбом, ISRC, хронометраж).
- Запрос передается на внутренний REST API (`http://127.0.0.1:43821/download-playlist`).
- **Двухуровневый резолвер потоков:**
  1. **SoundCloud API (`scsearch1:`):** Первичный источник. Отдает аудиопотоки AAC/M4A с высоким битрейтом без компрессии YouTube и, главное, **без троттлинга со стороны ТСПУ/DPI**.
  2. **YouTube Audio (`ytsearch1:`):** Резервный источник на случай редких или локальных релизов.
- Скачанные файлы получают полные ID3-теги и складываются в структурированные папки в `%USERPROFILE%\Music\Spotify Downloads\`.
- Путь автоматически прописывается в `prefs` клиента Spotify (`storage.local_files_sources`), делая треки сразу доступными в разделе «Локальные файлы».

### 3. Автодетект и отказоустойчивость локальных прокси

При работе в регионах с интернет-цензурой многие пользователи запускают локальные клиенты обхода блокировок. Если прокси жестко зашит в конфигурации, но программа закрыта — загрузчик зависнет по таймауту соединения (`ECONNREFUSED`).

Мы реализовали **Smart Zero-Hang Probing**:
1. При старте и перед каждой итерацией скачивания демон проводит легковесный TCP-опрос (таймаут 350мс) стандартных портов:
   - `10808` / `10809` — v2rayN, Xray, sing-box
   - `7890` / `7891` / `7897` — Clash, Clash Verge Rev, Mihomo
   - `2080` / `2081` — NekoBox, NekoRay
   - `40000` — Cloudflare WARP
   - `1080` — Shadowsocks, Outline
   - Системный прокси из реестра Windows (`HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings`)
2. Если активный прокси найден — он динамически передается в аргумент `--proxy`.
3. Если порт не отвечает — демон **не выдает ошибку**, а мгновенно переключается на прямой режим (Direct).

### 4. Исправление прав доступа и Crashpad (0x5 / 0x6D Fix)

Одна из главных причин появления «серого экрана» и мгновенного закрытия Spotify после модификации — механизм сбора дампов Google Crashpad:
- Если папка `%LOCALAPPDATA%\Spotify\User Data\Crashpad` имеет поврежденные дескрипторы безопасности или заблокированный файл `settings.dat`, системный вызов `TransactNamedPipe` внутри CEF завершается с кодом `0x6D` (`ERROR_BROKEN_PIPE`), после чего процесс принудительно вызывает `exit(1)`.
- Инсталлятор автоматически захватывает владение (`takeown`), переназначает права полного доступа для текущего пользователя (`icacls ... /grant :F`), генерирует валидный буфер `settings.dat` (4096 байт) и подготавливает папки `new`, `pending`, `completed`.

## 🛠 Конфигурация (config.json)

Файл настроек службы находится по адресу:
`%APPDATA%\SpotifyMod\companion\config.json`

```json
{
  "proxyEnabled": true,
  "proxyUrl": "socks5://127.0.0.1:10808",
  "downloadDir": "C:\\Users\\username\\Music\\Spotify Downloads",
  "activePreset": "direct",
  "autoBypass": true
}
```

- `proxyEnabled` *(boolean)*: Принудительное включение прокси. Если выключено — работает прямой автодетект.
- `proxyUrl` *(string)*: URL вашего локального прокси (`socks5://127.0.0.1:10808` или `http://127.0.0.1:7890`).
- `downloadDir` *(string)*: Пользовательская папка для сохранения аудиотреков.

## 🔄 Удаление (Rollback)

Чтобы полностью удалить мод и вернуть официальный клиент Spotify в девственное состояние:

```powershell
& "$env:APPDATA\SpotifyMod\uninstall.ps1"
```

Скрипт:
1. Восстанавливает оригинальный архив `xpui.spa` из резервной копии `xpui.spa.bak`.
2. Останавливает службу `SpotifyCompanionDaemon` и удаляет ярлык из автозагрузки Windows (`shell:startup`).
3. Сбрасывает кэш браузера CEF, возвращая клиент к заводскому состоянию без переустановки.

## 🔍 Диагностика и Troubleshooting

<details>
<summary><b>Spotify открывается, но через 2 секунды закрывается</b></summary>

Убедитесь, что служба Crashpad имеет доступ к файлу настроек. Запустите в PowerShell от имени пользователя:
```powershell
icacls "$env:LOCALAPPDATA\Spotify\User Data\Crashpad" /grant "${env:USERNAME}:(OI)(CI)F" /t
```
</details>

<details>
<summary><b>Кнопка «Скачать» пишет «Companion не запущен»</b></summary>

Проверьте статус службы в терминале:
```powershell
curl.exe http://127.0.0.1:43821/ping
```
Если ответ не приходит, перезапустите службу вручную:
```powershell
powershell -ExecutionPolicy Bypass -File "$env:APPDATA\SpotifyMod\companion\start.ps1" -Restart
```
</details>

<details>
<summary><b>Установлена версия Spotify из Microsoft Store</b></summary>

Версия из Windows Store изолирована в системном контейнере WindowsApps и блокирует изменение бинарных файлов. Установщик предупредит об этом. Рекомендуется удалить версию из Store и позволить `install.ps1` установить официальный Win32-дистрибутив.
</details>
